
# CampusX - Educational Portal

CampusX is a comprehensive educational portal designed for students, teachers, and administrators to manage academic activities, track progress, and facilitate communication within an educational institution.

## Features

### Student Portal
- **Dashboard:** At-a-glance view of semester performance, attendance, and fee status.
- **Subjects:** View subjects for the current semester and the teachers assigned.
- **Tests:** Take available online tests and view results for completed ones.
- **Results:** Check detailed semester-wise performance including SGPA and CGPA.
- **Time Table:** Access the weekly class schedule.
- **Events:** Stay updated on upcoming college events.
- **Profile Management:** View and edit personal profile details.

### Teacher Portal
- **Dashboard:** Overview of assigned classes, total students, active tests, and today's schedule.
- **My Classes:** View assigned classes and click to see detailed student rosters, subjects, and the class timetable.
- **Test Management:** Create, manage, publish, and close online tests.
- **Submission Tracking:** View detailed test submissions for each student, including their scores and the class average.
- **Event Management:** Add, edit, and remove campus-wide events.
- **Profile Management:** View and edit personal profile details.

### Admin Portal
- **Dashboard:** A central hub for administrative functions.
- **Manage Teachers:** Add, view, edit, and remove teacher profiles.
- **Manage Students:** Add, view, edit, and remove student profiles.
- **Manage Classes:** Create new classes, assign students and teachers, and define subjects for each class.
- **Manage Departments:** Create and manage departments. Assign students, teachers, and classes to specific departments.
- **Profile Management:** View and edit personal admin profile.
- **Bulk Upload:** Upload student results and fee records via CSV/JSON.
